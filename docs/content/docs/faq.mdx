## General Questions

### What is Vespra Canvas?

Vespra Canvas is an open-source "Cursor for Designers" that enables designers to make live edits to React and TailwindCSS projects directly within the browser DOM. It provides a seamless integration between design and development.

### Is Vespra Canvas free to use?

Yes, Vespra Canvas is completely open-source and free to use. You can clone the repository from [GitHub](https://github.com/Vespra-Company/vespra-canvas) and run it locally.

### What types of projects can I build with Vespra Canvas?

Vespra Canvas works with any React and TailwindCSS project. You can build websites, web applications, dashboards, and more.

## Technical Questions

### What technologies does Vespra Canvas use?

Vespra Canvas is built with:
- Next.js
- Drizzle
- Supabase
- Bun

### Can I use Vespra Canvas with my existing project?

Yes, Vespra Canvas will run on any Next.js + TailwindCSS project. You can import your project and start editing right away.

### How does Vespra Canvas compare to similar tools?

Vespra Canvas is an open-source alternative to tools like Bolt.new, Lovable, V0, and Figma Make, with its own unique features and approach to the design-to-code workflow.

## Getting Help
